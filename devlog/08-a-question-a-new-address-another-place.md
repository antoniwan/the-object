# a question, a new address, another place

*versions 1.0.1 to 1.1.2 · 28 october 2026*

It has a face for strangers now: a picture when the link is shared, icons, a small text file for machines that read the web. None of them say what it is.

It moved to its own address: https://the-object.antoniwan.online. The old one sends you there.

After the end of the arc, it asks one thing. It does not ask in words. There is no wrong answer and no reward for answering. It is the only thing that ever leaves your browser, and it is counted without knowing who you are.

The crash came back. On Edge on Windows the page would not open: the shader had crept back to drawing the scene in several places, and Direct3D compiles slowly. It is drawn in one place now, the same picture, about one second to start instead of six. The rule that keeps it that way is written down so it does not happen a third time.

And it is on itch.io: https://antoniwan.itch.io/the-object. The same object, updated whenever the site is. The site stays its home.
