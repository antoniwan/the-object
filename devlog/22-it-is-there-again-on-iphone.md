# it is there again on iphone

*version 1.8.4 · 29 october 2026*

For a few hours, on an iPhone, the room was empty.

Everything else was there: the white room, the floor, the light gathered where it should have been standing. It was not. The last version taught it to look only where something could be, and Safari on iPhone does its arithmetic in a slightly different order than other browsers. That order lost the place where it was, so nothing was drawn there.

It chooses that place differently now, in a way no browser can reorder. It is back.
