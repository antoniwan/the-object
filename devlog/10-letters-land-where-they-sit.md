# letters land where they sit

*version 1.2.0 · 28 october 2026*

A hand was the only way in. Now there is a second one.

The keyboard reaches it, and not as a copy of the hand. A letter lands on it where that key sits. Held, a letter hums. It can breathe with you. The room can be tipped.

It has a word of its own by now, and it can be answered.

None of this replaces anything. A hand still does everything it did before. The keys only do what a hand cannot.
