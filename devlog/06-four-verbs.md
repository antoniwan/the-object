# four verbs

*version 0.8.0 · 28 october 2026*

Four new things a hand can do to it, and four new things it becomes.

A flower. A thread longer than the room, which is also an instrument. A glass with a universe inside it. A box, which wants to be knocked on, and which lets something out.

Each one is earned the way the others are: by doing an ordinary thing to it a little more than necessary. Each one has a way back, and the way back is a gentler version of the way in.

Every shape in it is still an equation. The shader grew to hold these four without getting slower to start, which is now a rule the project keeps.
